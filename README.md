## 这个项目是什么？

本仓是「拼豆 AI 纠错工具」的**战略规划沉淀仓**，不包含任何产品代码。

包含从方向决策、需求推演、竞争分析、产品定义、技术路线、商业变现，到 GodotHarbor 项目止损决策的完整思考过程和所有结论。后续产品正式立项和开发时，所有决策依据都从这里出发。

---

## 核心卖点（差异化）

> **手机摄像头扫描拼豆板实物 → CV 识别每颗珠子的位置和颜色 → 自动对比图纸 → 标红所有错摆位置**

全市场唯一能做到「感知板子实际状态并自动纠错」的产品。现有所有开源/商业/智能硬件都停留在「图纸生成 + 手动标记」阶段，没有任何产品做过"拍照识别实物 + 自动对比纠错"的闭环。

## 演进路径（三步走总览）

```
Stage 1（现在，2-3 周 MVP）
  拼豆场景切入
  纯软件 MVP：俯拍纠错 + 分色引导
  目标：1000 免费用户 / 50-100 付费 / ¥500-5000 收入
  ↓ 验证 H1-H5 全部假设
Stage 2（中期，3-12 个月）
  横向扩展品类：十字绣 / 钻石画 / 数字油画
  社区冷启动：图纸分享 + 作品归档 + 云同步订阅
  目标：1-5 万用户 / 月入 ¥5k-5w
  ↓ 形成 UGC 飞轮 + 数据壁垒
Stage 3（长期，12 个月+）
  硬件壁垒：透光板 + 底部摄像头（实时纠错+引导）
  电商闭环：一键购买色料包
  创作者市场：付费图纸分发
  目标：月营收 ¥5w+ / 利润率 > 40%
```

## 待验证的 5 条核心假设（MVP 阶段必须回答）

| 编号 | 假设 | 成功标准 |
|---|---|---|
| **H1** | 用户愿意为「俯拍自动找错」功能付费（避免返工） | MVP 付费率 5-10% |
| **H2** | 「分色号引导」比「按区域摆」实际效率更高（用户体验到并认同） | 分色引导使用率 > 15%，A/B 测试完成一组作品快 30%+ |
| **H3** | CV 识别准确率 > 90% 时用户足够满意 | 用户主动标记"我没摆错"率 < 10%，调研满意度 > 80% |
| **H4** | 3 次/天免费限制是合理的（不太低也能触发付费） | 付费墙→购买转化率 > 5%；A/B 测试 3 次 vs 5 次验证 |
| **H5** | 小红书/抖音内容投放能以 < ¥5/用户成本获客 | 后台渠道数据 CAC < ¥5 |
